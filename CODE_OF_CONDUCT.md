# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be civil, argue about the work and not the person, and assume the
other side is trying to get it right. Review here is blunt about code because
the code is meant to be trusted with other people's assumptions; it should
never be blunt about people.

To report behavior that breaks this, contact the maintainer
([@dannycake](https://github.com/dannycake)) through GitHub. Reports are kept
private.
